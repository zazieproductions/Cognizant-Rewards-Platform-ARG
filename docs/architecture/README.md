# Architecture documentation

System-level explanation of how Cognizant Rewards Platform is built.

The canonical architecture document is
[`ARCHITECTURE.md`](../../ARCHITECTURE.md) at the repository root. It covers the
full system: lifecycle, modules, state, rendering, audio, data, event flow,
build, performance, design decisions, and limitations, with Mermaid diagrams.

The docs in [`docs/technical/`](../technical/) go one level deeper per subsystem,
and the pull-request template in
[`.github/pull_request_template.md`](../../.github/pull_request_template.md)
keeps changes aligned with the architecture.
